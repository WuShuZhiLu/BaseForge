F · 交互与快捷键

触发行为
Ctrl/Cmd+F打开浮层并聚焦输入；若编辑器有 ≤100 字选区，预填该文本并自动选中
Ctrl/Cmd+H打开并直接展开替换行，焦点落在替换输入
Enter / Shift+Enter下一个 / 上一个；到达末尾循环回第一个
Alt+Enter全部替换（需二次确认，提示「将替换 N 处」）
Tab / Shift+Tab在输入框与 9 个按钮间循环，焦点环统一为 0 0 0 3px accent/6%
Esc关闭浮层、清除命中高亮、焦点还给编辑器（保留滚动位置）
关闭后重开同一编辑器内记住「替换行是否展开」与三个选项开关；查询词随关闭清空

G · 落地方式

1. 新建 components/DocFindBar.tsx：纯受控 UI（value / matchCount / activeIndex / options / callbacks），不含搜索逻辑。
2. SearchReplacePanel.tsx 保留 ProseMirror 装饰扩展，删掉 JSX，改为渲染 DocFindBar。
3. Markdown 侧把 @codemirror/search 的 search({createPanel}) 换成自定义 panel：panel 内挂一个 React root 渲染同一个 DocFindBar，命中态由 SearchQuery 的 matches 驱动。
4. 命中高亮统一到 CSS 变量（--find-hit / --find-hit-active），PM 的 .search-match 与 CM 的 .cm-searchMatch 同时引用。
5. 现有 i18n 键 searchReplace.* 全部复用，新增仅「无匹配」「正则表达式无效」两条。
