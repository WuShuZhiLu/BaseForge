Tab 结构（A+B 合体）

  • 概览：跨项目——全部工单环形图、整体完成率、逾期、项目进度卡（图像化）
  • 看板 / 列表：当前项目（侧栏选中）全类型视图，类型用色条 + 筛选 chip 区分
  • 设置：基本信息 + 类型管理（复用 M3 B5）

侧栏拖拽（学知识库侧栏）

  • 工单行 draggable，四个状态分组为放置区，拖入即改状态（复用 M3 的 update 接口）
  • 拖拽中目标分组高亮；与知识库侧栏的拖拽交互语言一致
  • hover 仍保留「标记完成 / 在主区打开」快捷

概览数据面

  • 跨项目聚合需一个后端端点（GET /api/pm/overview：各项目计数/状态分布/逾期），实现时补
  • 图形：环形（conic-gradient，零依赖）+ 进度条；不动图表库

实现范围

  • PmCenter：Tab 栏（概览/看板/列表/设置）+ 概览页 + 现有看板/列表/设置挂入
  • SidebarNext ProjectsSidePanel：工单行 draggable + 分组 dropzone + 状态变更
  • backend：/api/pm/overview 聚合端点
  • Rail / 宿主壳零改动

方向确认即落地实现。
