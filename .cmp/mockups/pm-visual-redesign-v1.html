可对比的点：侧栏的分组导航（彩色线性图标 + 组名 + 计数右对齐，对齐 PingCode 待办区）· 工单行带 #编号 与逾期红字 · 主区工具条改为两段式（项目身份 + 语义统计色点 / 筛选行带 ⌘/ 快捷提示）· 看板列头色带与卡片类型色条 · 卡片信息层级：类型 → 编号 → 优先级 / 标题两行 / 标签 / 负责人+截止+交付文档 · 空列不再是一个孤零零的「空」字。

① 侧栏项目面板（之前：裸文本堆叠）

  • 项目选择：色块 + 名称 + 未完成计数徽标 + 选中态（accent 浅底描边）
  • 状态分组：彩色圆角图标底 + 组名 + 计数右对齐（同 PingCode「待办」区语言）
  • 工单行：#编号（等宽字体）+ 标题单行截断 + 逾期红字；hover 出底
  • 底部动作按钮化：新建工作项（主色）/ 在主区打开看板 / 新建项目

② 主区工具条（之前：控件一行硬排）

  • 第一行 = 项目身份（立方色块 + 名称 + KEY 徽标）+ 语义色点统计 + 视图分段 + 主行动实心按钮
  • 第二行 = 筛选：搜索（带 / 快捷提示，接标题/描述/编号）+ 类型/标签/平台 chips + 右侧计数说明
  • 控件按「主 → 次 → 系统」排序，用分隔线与间距分组，不再等权排开

③ 看板（之前：裸列 + 孤字空态）

  • 列头 3px 状态色带（琥珀/蓝/紫/绿）+ 彩色图标底 + 计数 + 列内 ＋
  • 卡片：左侧 类型色条、类型 chip、KFX-nn 编号、优先级、两行标题、标签、负责人圆标 + 截止（逾期红）+ 交付文档计数
  • hover：描边 + 抬升阴影（示意卡片已演示）；空列：虚线框 + 「拖拽工单到这里」

④ 范围边界 + 字段零增删

  • Rail＝宿主导航，如实还原图标列；PM 在 Rail 上只有「管」徽章（插件徽章体系），不增不改
  • PM 可配置范围＝侧栏「项目面板」内容 + 主区页面（PmCenter）
  • 全部使用已实现字段：项目色 / 类型(typeConfig) / 状态 / 优先级 / 截止 / 标签 / itemNo 编号 / 交付文档 / 负责人（占位头像）
  • 落地文件：SidebarNext 的 ProjectsSidePanel + PmCenter（工具条/看板/列表/空态）
