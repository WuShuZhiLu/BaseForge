结构（你的定位）

  • 侧栏 = 模块导航：概览 / 看板 / 列表 / 设置（图标 + 名称 + 计数）+ 项目选择 + 状态分组速览
  • 主区 = 模块内容：概览（跨项目图表）/ 看板 / 列表 / 设置，随侧栏选择渲染，主区不再有 Tab 栏
  • Rail 宿主固定；PM 在 Rail 上只有「管」徽章

交互关系

  • 看板模块选中时，侧栏展开状态分组（拖拽改状态 + 点组头过滤看板）
  • 概览模块 = 跨项目仪表盘（环形图 / 进度卡 / 分布图），点项目卡 → 切到该项目看板
  • 工单行点击 → 打开详情抽屉（沿用 M3）

实现范围

  • SidebarNext ProjectsSidePanel：模块导航态（概览/看板/列表/设置）+ 状态分组拖拽
  • PmCenter：按模块渲染四个视图容器，概览接 /api/pm/overview 聚合端点
  • Rail / 宿主壳零改动
