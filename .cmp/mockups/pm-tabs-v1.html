分离逻辑（你说的意思，请确认）

  • 概览 = 纯数据：状态统计卡 + 整体进度条 + 最近动态（活动流聚合）
  • 需求 / 任务 / 缺陷 = 按 typeConfig 动态生成的模块 Tab，各自独立看板（默认）+ 列表切换
  • 设置 = 基本信息 + 工单类型管理
  • 统计胶囊、筛选框不再常驻看板上方——各回各家

与 PingCode 的映射

  • PingCode 项目内导航：需求 / 迭代 / 任务 / 缺陷 / 设置（带计数）
  • 我们的 Tab：概览 / [类型…] / 设置——类型来自项目 typeConfig，增删类型 Tab 实时跟随
  • 迭代/里程碑（E1）未来作为新 Tab 插入「概览」与「设置」之间

备选方案（如果你要的是另一个形状）

  • 方案 B：固定四页 概览 / 看板 / 列表 / 设置（不按类型拆 Tab，类型做看板内分组）
  • 方案 C：Tab 只分 工作项 / 设置，类型筛选保留在看板内

选 A / B / C，或者说你的分法。

落地范围

  • PmCenter 主区改造：身份行保留 + 新增 Tab 栏 + 四类视图容器（Rail/侧栏零改动）
  • 概览页新增内容：整体进度条 + 最近动态（活动流聚合接口，M3 已有 logs 数据）
  • 类型 Tab = typeConfig.map + 按 type 过滤的看板/列表
