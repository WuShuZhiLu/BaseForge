> 本文档写给负责写代码的 agent。原型 HTML 是**唯一视觉与交互事实源**，本文档把其中"侧栏"部分提炼为可实施的规格。读完本文 + 打开原型操作一遍，即可动工。

- 设计流程：原型先行。原型定稿 → 按原型写代码 → 回到原型继续设计下一区域。
- **原型文件（最新定稿，勿修改）**：
  - `prototypes/base-notes-current.html` —— 轮 15 定稿，单文件、无构建、可直接浏览器打开
  - `prototypes/base-notes-current.backup-20261017-r15.html` —— 同内容备份
  - `prototypes/base-notes-current.backup-20261017-r12.html` / `...-20261017.html` —— 历史版本，仅对照用
- 代码库：nowen-note 仓库（本地路径由使用者提供给 agent）。**agent 第一步**：阅读现有 sidebar 相关代码，确定框架/组件/状态管理映射；本文只定义行为与视觉规格，不指定实现方式。

## 2. 本批次范围 / 非范围

**范围内（本次实现）**：侧栏（Sidebar）整体——头部、三面板结构、知识树、标签树、专注模式、行级菜单、拖拽、面板沉底。

## 4. 交互规格（照此实现，参数以原型为准）

### 4.1 侧栏头部（48px，border-bottom 与全窗头带对齐）

布局从左到右：**位置按钮 → 搜索输入框（flex:1 占满）→ 筛选按钮**。

- **位置按钮**：home 图标 + 空间名（如"个人空间"）+ 下拉 chevron；点击弹出空间列表（个人空间 ✓ / 团队空间 / 加入空间），点选后同步名称并关闭；chevron 随展开旋转 180°。
- **搜索输入框**：magnifier 图标 + input（placeholder"搜索"）；**样式：半透明底**（亮 `rgba(17,24,39,.05)` / 暗 `rgba(255,255,255,.06)`）、无边框、hover 加深一档、**聚焦时实底 + accent 描边**。输入实时过滤知识树（语义见 4.4）。
- **筛选按钮**：漏斗图标，弹出范围浮层（全部 / 仅文件夹 / 仅笔记），非默认范围时按钮高亮。与搜索关键词 AND 组合。
- 空间切换**只在侧栏头部**，头像菜单不管空间（头像菜单只有账号 + 外观）。

### 4.2 三面板结构（VS Code 式）

- 容器：`知识库 / 标签 / 打开的编辑器` 三个 section 纵向排列于一个滚动容器。
- **区段头**：chevron（点击折叠/展开整个区段）+ 标题 + 右侧操作钮 + 计数徽章；区段头可**拖拽排序**（HTML5 DnD 或等价）。
- 区段头操作钮：
  - 知识库：`折叠全部文件夹`（toggle：有展开则全折/全折则全展，图标态随状态翻转）· `新建文件夹`（追加 lv1 节点并进入重命名）· `⋮ 更多`（菜单：全部展开 / 全部折叠）· 计数徽章（笔记总数）
  - 标签：`折叠全部标签文档` · `刷新` · 计数徽章（标签数）。**无搜索按钮**（已删除，不要实现）
  - 打开的编辑器：`全部关闭`（×圆圈）· 计数徽章。**无折叠钮**（折叠区段用区段头 chevron）

### 4.3 知识树（核心）

**数据模型**：树形（知识库→文件夹→文档，任意层级）。原型示例数据（定稿）：

```
产品设计(2)
  ├ 信息架构 v2 / 导航栏改版讨论
技术笔记(5)
  ├ 嵌入式(3)：CH585 驱动重构 / STM32 CMSIS 版本差异 / BLE OTA 升级方案(置顶📌,当前)
  └ 移动端(2,折叠)：Flutter Isar 持久化 / Flutter 设备连接稳定性方案
硬件项目(2,折叠)：nrf52840 分体键盘布线 / OLED 安装支架 3D 模型
键盘项目(3,折叠)：Dactyl Manuform SCAD / 键帽配置文件 / 轴体选型对比
```

- **根层 = 知识库**（上例 4 个），lv2/lv3 是普通文件夹；文档计数徽章显示"直属+子孙文档总数"，与区段徽章调和。
- **缩进**：每层 16px（原型内边距 2/18/34px），chevron 列宽 20px；折叠组 chevron 旋转 -90°（过渡 0.15s）。
- **图标**：文件夹 amber、富文本文档 accent、Markdown 文档 emerald、置顶文档带 📌（pin）。
- **可见性引擎**（语义，实现方式不限）：
  1. 无关键词：折叠组的后代隐藏，组自身可见；
  2. 关键词激活：**忽略折叠态**，自身或后代匹配的行显示（匹配路径自动展开），其余隐藏；无结果显示空态"无匹配的文件夹或笔记"；
  3. 筛选 scope：仅文件夹/仅笔记 = 类型过滤 + 祖先路径保留，关键词与 scope AND；
  4. 行隐藏用 class（如 `kt-fold`），**不要**直接改行内 style.display 与其他逻辑打架。

### 4.4 标签树

两层：标签（色点 10px + 名 + 文档数）→ 文档行。示例：BLE(3,展开)/Flutter(2)/硬件(5)/OpenSCAD(1)/PCB(2)，其余默认折叠。文档行可重名（同一文档可挂多标签）。

### 4.5 专注模式（仅根层）

- **触发**：**双击** lv1 知识库行（lv2/lv3 不响应；单击仍是折叠/展开）。
- **效果**：知识树只显示该知识库的子树；区段体顶部出现**专注条**：`[← 返回] 知识库名`（accent 底色块）；进入时目标若折叠则自动展开。
- **退出**：点返回箭头或 Esc。Esc 优先退专注，其次清空搜索。
- 专注中：搜索/筛选/折叠全部照常但只作用于该子树；"折叠全部文件夹"不碰专注范围外的节点。
- 实现提示：原型用"可见性 mask"（全树扫描后强制隐藏范围外行），代码里等价于临时切换 root + 过滤，任选。

### 4.6 行级 ⋮ 菜单（fixed 定位浮层，挂 body，点外/Esc 关闭；底部越界向上翻转）

| 行类型 | 菜单项 |
|--------|--------|
| 知识库区段头 ⋮ | 全部展开 / 全部折叠 |
| 文件夹（kb 树） | 新建文档 / 新建子文件夹 / 重命名 / 删除（红） |
| 文档（kb 树） | 置顶/取消置顶 / 重命名 / 删除（红） |
| 标签组 | 重命名 / 删除（红） |
| 标签文档 | 定位 / 重命名 / 删除（红） |

- **新建子项**：插入到父节点全部后代之后；父节点折叠则先展开；随即进入重命名。
- **重命名**：行内 input 替换标题；Enter/失焦提交、Esc 取消（防双触发）。
- **删除**：整子树删除（文件夹连后代）。
- **置顶**：文档行 pin 图标切换（真实置顶排序归数据层，本批次只做标记）。
- **定位**：在知识树中按标题找到该文档 → 目标不在当前专注知识库则先退专注 → 展开全部祖先 → 滚动到可见 + 高亮闪烁 1.6s（accent 底渐隐）。找不到同名文档则静默关闭菜单。

### 4.7 拖拽（仅 kb 树；标签树不做）

- 行 draggable；目标行**上 30% = 插到其前（同层）、下 30% = 插到其后（同层）、中间 = 移入该文件夹**（文档目标无"移入"，折叠为前/后）。
- 指示：上方 2px accent 内边线 / 下方 2px 内边线 / 移入时行 accent 底色；拖动行半透明。
- 整子树移动，层级与缩进自动重算；**禁止移入自身子树**；移入折叠文件夹自动展开。
- 与专注/搜索叠加：不可见行不作为拖放目标；drop 后重新计算可见性。

### 4.8 面板沉底（VS Code 语义）

- **知识库之外**的面板（标签、打开的编辑器）折叠后沉到侧栏底部；多个折叠时**紧贴成组**（中间不留空隙），空白全部在展开内容与折叠组之间。
- 知识库折叠保持原位不下沉。
- 原型实现供参考：`.collapsed:not(#kbSection) { margin-top: auto }` + 后续兄弟折叠面板 `margin-top: 0`（注意 flex 中多个 auto 会**平分**空白，必须归零后续项——原型踩过这个坑）。

### 4.9 打开的编辑器面板

行 = 文档图标 + 标题 + hover 关闭 ×；激活行 accent 底；关闭激活行后相邻行补位激活；全部关闭显示空态"没有打开的编辑器"。打开/切换文档与编辑器区的联动若现有代码已有机制则接入，没有则先只做面板内交互。
